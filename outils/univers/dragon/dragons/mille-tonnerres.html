Description

Le Mille Tonnerres est un dragon marin à deux têtes qui génère de puissantes décharges électriques. Ces deux têtes coordonnent leurs attaques pour maximiser les dommages - l'une chargée positivement, l'autre négativement - créant des arcs électriques dévastateurs. Excellent nageur, il peut électrocuter quiconque se trouve dans l'eau à proximité.

Capacités

  • Décharges électriques
  • Arc électrique entre les deux têtes
  • Électrocution aquatique
  • Nage puissante
