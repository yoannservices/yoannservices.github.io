# Game Tools Lab

Suite d'outils et de calculateurs pour le jeu vidéo et les périphériques.

**▶ Démo en ligne : [https://yoannservices.github.io/game-tools-lab/](https://yoannservices.github.io/game-tools-lab/)**

## Fonctionnalités

- Tests souris : CPS (clic gauche / droit), double clic, glisser, molette, polling rate
- Tests clavier : APM, Spacebar Clicker, compteur de frappes
- Réflexes : test de réaction visuel et auditif
- Écran et performance : moniteur FPS, infos écran, ping, test micro
- Calculateurs : eDPI, conversion de sensibilité entre jeux…
- Historique des résultats (`localStorage`)

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000 (dans le dossier `web/` de Mes Projets : http://localhost:8000/outils/game-tools-lab/).

## Structure

- `index.html` : la page
- `style.css` : les styles
- `script.js` : la logique

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build.
