# Unit Converter

Convertisseur d'unités universel, avec devises en temps réel.

**▶ Démo en ligne : [https://yoannservices.github.io/outils/unit-converter/](https://yoannservices.github.io/outils/unit-converter/)**

## Fonctionnalités

- Longueur, masse, température, volume, vitesse, données, temps, surface, énergie, pression et angle
- Devises au taux du jour (API open.er-api.com)
- Historique des conversions (`localStorage`)

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000 (dans le dossier `web/` de Mes Projets : http://localhost:8000/outils/unit-converter/).

## Structure

- `index.html` : la page
- `style.css` : les styles
- `script.js` : la logique

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build.
