# Pièces Détachées Téléphone

Trouver les meilleurs sites de pièces détachées pour son modèle de téléphone.

**▶ Démo en ligne : [https://yoannservices.github.io/outils/pieces-detachees-tel/](https://yoannservices.github.io/outils/pieces-detachees-tel/)**

## Fonctionnalités

- Choix de la marque puis du modèle
- Liste de sites classés par pertinence (note globale × spécialisation par marque), tous vendant aux particuliers

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000 (dans le dossier `web/` de Mes Projets : http://localhost:8000/outils/pieces-detachees-tel/).

## Structure

- `index.html` : la page
- `style.css` : les styles
- `script.js` : la logique

## À savoir

Les données sont indicatives : vérifiez disponibilité et prix directement sur les sites.

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build.
