# Générateur de CV

Générateur de CV avec aperçu en direct et export PDF.

**▶ Démo en ligne : [https://yoannservices.github.io/generateur-cv/](https://yoannservices.github.io/generateur-cv/)**

## Fonctionnalités

- Formulaire par sections : infos personnelles, accroche, expériences, formation, compétences, langues, centres d'intérêt, certifications
- Aperçu en direct, 3 modèles (Classique, Moderne, Minimal) et choix du thème
- Export PDF (via l'impression du navigateur)
- Sauvegarder / Charger et réinitialiser (`localStorage`)

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000 (dans le dossier `web/` de Mes Projets : http://localhost:8000/outils/generateur-cv/).

## Structure

- `index.html` : page, styles et script dans un seul fichier

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build. Tout tient dans un seul fichier.
