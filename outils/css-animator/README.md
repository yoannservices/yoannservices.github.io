# CSS Animator

Éditeur visuel d'animations CSS `@keyframes`, avec aperçu et export du code.

**▶ Démo en ligne : [https://yoannservices.github.io/css-animator/](https://yoannservices.github.io/css-animator/)**

## Fonctionnalités

- Élément de prévisualisation : boîte, cercle, texte ou image (couleur, taille)
- Réglages : nom, durée, délai, répétitions, direction, fill mode, timing (ease, linear, steps, spring…)
- Préréglages : Fade In, Slide, Zoom, Bounce, Shake, Spin, Pulse, Flip, Rubber
- Édition des keyframes et CSS généré prêt à copier

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000 (dans le dossier `web/` de Mes Projets : http://localhost:8000/outils/css-animator/).

## Structure

- `index.html` : la page
- `style.css` : les styles
- `script.js` : la logique

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build.
