# Tableau Périodique

Tableau périodique interactif des 118 éléments.

**▶ Démo en ligne : [https://yoannservices.github.io/tableau-periodique/](https://yoannservices.github.io/tableau-periodique/)**

## Fonctionnalités

- Les 118 éléments avec leur fiche détaillée (clic sur un élément, Échap pour fermer)
- Filtres par catégorie (non-métaux, gaz nobles, métaux alcalins, halogènes, lanthanides…), par bloc (s, p, d, f) et par période
- Coloration au choix : catégorie, état physique ou électronégativité

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000 (dans le dossier `web/` de Mes Projets : http://localhost:8000/education/tableau-periodique/).

## Structure

- `index.html` : la page
- `style.css` : les styles
- `script.js` : la logique

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build.
