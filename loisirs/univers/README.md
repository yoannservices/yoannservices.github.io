# Mes Univers

Encyclopédie de personnages : *Dragons* (DreamWorks) et *One Piece*.

**▶ Démo en ligne : [https://yoannservices.github.io/loisirs/univers/](https://yoannservices.github.io/loisirs/univers/)**

## Fonctionnalités

- Page d'accueil pour choisir un univers
- Dragons : personnages et créatures avec leurs images
- One Piece : pirates, équipages, primes et légendes de Grand Line

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000 (dans le dossier `web/` de Mes Projets : http://localhost:8000/loisirs/univers/).

## Structure

- `index.html` : choix de l'univers
- `dragon/` : `index.html`, `les-dragons.html`, `personnages.html`, dossiers d'images `dragons/` et `personnages/`
- `one-piece/` : `index.html`, `personnages.html`, `personnage.html`, `data.js`, `script.js`

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build.
