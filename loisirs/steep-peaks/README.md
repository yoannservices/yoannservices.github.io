# Steep Peaks

Sports de montagne en monde ouvert (Three.js, sans bundler ni node_modules : import map). Le monde est généré par code ; seuls le skieur et le snowboardeur sont de vrais modèles .glb (crédits dans `assets/models/CREDITS.md`).

Lancer depuis la racine du site : `npx http-server loisirs/steep-peaks -p 5174 -c-1`
