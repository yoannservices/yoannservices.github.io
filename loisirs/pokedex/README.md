# Pokédex Complet

Encyclopédie interactive des 1025 Pokémon.

**▶ Démo en ligne : [https://yoannservices.github.io/loisirs/pokedex/](https://yoannservices.github.io/loisirs/pokedex/)**

## Fonctionnalités

- Les 9 générations (1 à 1025), chargées au fur et à mesure (« Charger plus »)
- Filtres par type et par génération
- Tri par numéro, nom, PV, attaque ou vitesse
- Fiche détaillée de chaque Pokémon

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000 (dans le dossier `web/` de Mes Projets : http://localhost:8000/loisirs/pokedex/).

## Structure

- `index.html` : la page
- `style.css` : les styles
- `script.js` : la logique

## À savoir

Une connexion Internet est nécessaire (données PokéAPI).

## Technologies

HTML, CSS et JavaScript ; données et images via [PokéAPI](https://pokeapi.co/).
